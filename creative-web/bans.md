# Bans

Every ban has a replacement. Do the replacement. Escaping a ban into another ban on this page is a failure. If the user named a style that appears here, the user's style wins (`SKILL.md`).

## Basic page

| Ban | Why it fails | Do this instead |
|---|---|---|
| Centered headline on an empty field, big type, blank bands | The page is just text | The dealt world's scene, filling the first viewport |
| Hero, then three equal feature cards, a bento, cards inside cards | Same grid as every other page | Content as objects in the objects table |
| The same rhythm on every section: heading, text, card grid | The page is a template with the words swapped | A different rhythm per section, listed in the plan |
| Motion that only decorates (bobbing icons, generic fade, idle wiggle) | It does not tell a brand truth | Motion that enacts one of the three truths |
| Photographs in mixed grades, crops, or styles | Not art-directed | One grade for the whole page. Missing assets marked placeholder |
| Purple, blue, or indigo gradients, gradient blobs, glow | The universal default costume | 2 to 5 hex values from the brand's material |
| Inter, Roboto, Open Sans, Lato, Arial, system-ui as the display | No decision was made | A display face that belongs to the world |
| Space Grotesk, Syne, DM Mono, DM Sans, Geist, Poppins, Montserrat as the display | The next font default | A face chosen for this material, named in the plan |
| Glass panels, `backdrop-filter` blur as the surface | Fake premium | The concept's real material |
| Emoji as icons, a generic line-icon set | Template kit | Drawings from the picture rule, or no icons |
| Soft shadow and the same large radius on every card | Kit styling | Shadows only as a second piece of material, radii from the object |
| Buzzwords: seamless, unlock, elevate, transform, innovative, next-level, cutting-edge, "Welcome to" | No voice | The voice lines from the plan |
| Fake logo walls, fake quotes, fake counters, skill bars, invented metrics | Nothing here is true | Harvest facts, shown as objects. Mark sample data as sample |

## Award-site costume

What appears when someone asks for a page that looks impressive. These are bans too.

| Ban | Do this instead |
|---|---|
| Canvas particle network (dots joined by lines) | A generative piece that is the concept, or nothing (`techniques.md` item 26) |
| Custom cursor that is a ring plus a dot | A cursor that performs the concept's verb, or the native cursor |
| Fade-up `translateY(32px)` (also 30px or 40px) on every section | Static body text. Motion only on the budgeted moments |
| One easing on everything, especially `cubic-bezier(0.16, 1, 0.3, 1)` | The motion personality from the plan |
| Giant hollow marquee of skills or logos | A ticker only if the world has one (a departure board, a news ticker) |
| Noise or grain on every surface | Grain only when the harvest names print, film, or dust, opacity 0.05 to 0.12 |
| Black background plus one acid accent (`#E8FF47`, `#CCFF00`, `#B6FF3B`, `#39FF14`) | The room's real color, darkened. Only the concept's lamp glows |
| Scroll-jacking, or horizontal scroll for the main text | Native scroll. One short pin for the signature. Horizontal only for a gallery or a stack |

## The costume people adopt to escape the bans above

| Ban | Do this instead |
|---|---|
| Cream page near `#F4F1EA`, a high-contrast serif, a clay accent near `#D97757` or `#C46B3A` | Only if the harvest is actually paper, dough, or clay, and then show fiber, stain, or crumb, not a flat field |
| An italic serif word inside a sans headline (often a display italic) | One typographic idea from the concept |
| Section numbers 01, 02, 03, mono eyebrows on every heading, pill buttons | Labels in the world's own words (batch codes, ticket numbers, aisle marks) |
| Hairline rules on every edge and radius 0 as the whole personality | Layout from the object's shape. A perforation is a signature, not a system |
| Instrument Serif, or any "editorial" italic, as the shortcut to taste | The display face from the plan |

## Execution

| Ban | Do this instead |
|---|---|
| A signature that only works with a mouse | Design the tap or scroll version first |
| Detailed people, animals, or vehicles drawn in perspective as SVG | Geometric characters, abstract shapes, or one generated raster with a locked palette |
| Generated images in mixed styles | One prompt template per site: subject, composition, light, medium, palette. Same post-processing on all of them |
| Merging two concepts | One concept |
| An effect that does not express the concept | Delete it. This is the required removal |
| Copying a named site's concept or look | Derive from the harvest. A reference lends one decision |
| Repeated identical objects | Vary each one |
| Animation on menus, tabs, and other high-frequency actions | Instant, or under 150ms |
| No reduced-motion path | Keep the layout. Drop travel and pins |
| An intro that blocks the headline | Under 1.2s, skippable, absent on task-focused pages |
| A pin longer than 250vh | Shorten it. The visitor must not feel stuck |
