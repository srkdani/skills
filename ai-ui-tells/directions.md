# Art directions

Run `python3 draw.py "Product name" surface [salt]` from this folder. It prints one block. Use that block. Do not swap it for a direction you like more. Fonts live in `fonts/` beside this file. From a page saved at `eval/independent/src/`, the URL is `../../../fonts/FileName.ttf`.

## Direction: Split-flap board

World: an airport split-flap board in a dim hall.
Tie the subject to a board that updates one flap at a time.
Dominant band, full first viewport: `#14120E`.
Flap face: `#F2C200`. Flap ink: `#14120E`. Board ink: `#F4EFE4`.
Accent, primary button only: `#E24B2B`. Line: `#3A3428`.
Display: Anton, file `Anton-Regular.ttf`. Body: Syne, file `Syne-Variable.ttf`, weight 400.
Signature: one giant yellow flap. That flap is the bold place. Other flaps are quiet rows.
Layout: headline is stacked flaps on the left, product UI is a column of smaller flaps on the right, about 40 percent of the hero. No centered column. No icon cards.
Radii: 2 px on flaps, 0 on the band.
